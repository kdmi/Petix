# Ревил NFT-капсул: порядок действий

Ревил и открытие заливки питомцев — два разных момента. Сперва коллекция
показывает тиры, и только когда все капсулы доехали до витрины, открывается
посадка питомцев. Капсула, в которую питомца посадили сразу, никогда не покажет
владельцу картинку своего тира, а ради этого кадра ревил и делается.

## Порядок

1. **`NFT_MARKETPLACE_URL`** — боевая ссылка на коллекцию (это кнопка
   «Get capsules» в выборе капсулы).
2. **`NFT_ENABLED=1`** на Vercel и деплой. Оживают эндпоинт метаданных, конфиг
   для фронта и минутный крон. На витрине пока не меняется ничего: `baseURI` всё
   ещё преревильный. Заливка закрыта сама собой — `NFT_BIND_ENABLED` по
   умолчанию 0.

   Флаг обязан идти **раньше** смены `baseURI`: до него `/api/nft/metadata/*`
   отдаёт 404, и токены какое-то время указывали бы в пустоту.

3. **Дождаться индекса владельцев.** Крон читает Transfer-логи по
   `NFT_SYNC_MAX_BLOCKS` (250k) за прогон. У Robinhood Chain ~864k блоков в
   сутки, так что за каждые сутки с деплоя коллекции — примерно четыре прогона.
   Пока не догнал, держатель увидит пустой список капсул.

4. **Ревил:**

   ```bash
   node scripts/nft/set-base-uri.js https://petix.fun/api/nft/metadata/
   ```

   Слэш на конце обязателен, иначе SeaDrop отдаст всем токенам один JSON. Ключ
   владельца берётся из `.env.local` и никуда не уходит. Скрипт откажется
   работать, если ключ не от владельца коллекции.

5. **Обход витрины** крон запустит сам: он сравнивает `baseURI` с последним
   известным и при расхождении ставит обход всей коллекции. Идёт по
   `NFT_REFRESH_BATCH` (20) токенов в минуту.

6. **Проверка:**

   ```bash
   node scripts/nft/reveal-audit.js
   ```

   Сравнивает трейты каждого токена с тем, что о нём думает OpenSea. Сравнение
   считает сервер, локально нужен только `INTERNAL_API_SECRET`. Флаг
   `--refresh` заодно пинает отставших. Токен, по которому витрина не ответила,
   попадает в `unknown` и не засчитывается ни в плюс, ни в минус.

7. **Открыть заливку**, когда аудит покажет полное совпадение: админка →
   Tunable coefficients → «Seal pets into capsules» → 1. Деплой не нужен.

## Чего не делать после ревила

- **Не трогать поле преревильной картинки в OpenSea Studio.** Оно пишет
  `baseURI` и вернёт коллекцию в запечатанный вид.
- **Не менять `NFT_TIER_SEED`.** Раскладка тиров пересоберётся заново, и у всех
  капсул поменяется редкость.

## Откат

Тот же скрипт с прежним `ipfs://…` возвращает преревильное состояние. Крон
заметит смену `baseURI` и так же обойдёт коллекцию обратно.
